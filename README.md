# Personal Portfolio Website

A responsive personal portfolio website built with pure **HTML**, **CSS**, and **JavaScript** as part of the Web Fundamentals Day 2 Assignment.

## 🚀 Live Demo
> Deploy to GitHub Pages and paste the link here.

## 📁 Folder Structure
```
portfolio/
├── index.html      # Main HTML structure
├── style.css       # Styling with Flexbox & CSS variables
├── script.js       # Interactive JavaScript features
├── profile.png     # Profile photo
└── README.md       # This file
```

## ✅ Features

### HTML Sections
- **Hero / Introduction** — Name, greeting, and CTA buttons
- **About Me** — Bio, fun facts, and quick stats
- **Education** — Timeline of academic history
- **Skills** — Categorised skill cards with progress bars
- **Projects** — Project showcase cards with GitHub links
- **Contact** — Info panel + working contact form
- **GitHub Profile Link** — In the hero socials and About section

### CSS Highlights
- CSS custom properties (design tokens) for easy theming
- Dark / Light mode colour schemes
- Google Fonts (Inter + Fira Code)
- Flexbox & CSS Grid layouts
- Gradient accents, glassmorphism surfaces
- Smooth hover transitions and micro-animations
- Fully **responsive** (mobile, tablet, desktop)

### JavaScript Interactions (10 features!)
1. **Time-based greeting** — Changes based on time of day
2. **Typewriter effect** — Cycles through developer roles
3. **Dark / Light mode toggle** — Persisted in `localStorage`
4. **Mobile hamburger menu** — Animated open/close
5. **Active nav link** — Highlights current section on scroll
6. **Scroll reveal** — Cards animate into view on scroll
7. **Skill bar animation** — Bars fill when scrolled into view
8. **Skills tabs** — Switch between Frontend / Backend / Tools
9. **Contact form validation** — Live validation + simulated send
10. **Navbar shadow** — Appears on scroll

## 🛠️ Tech Stack
- HTML5 (semantic elements)
- CSS3 (Flexbox, Grid, Custom Properties, Animations)
- Vanilla JavaScript (ES6+, IntersectionObserver)
- Font Awesome 6 icons
- Google Fonts

## 📱 Responsive Design
The site adapts gracefully across:
- **Mobile** (< 680px) — Hamburger menu, stacked layout
- **Tablet** (< 900px) — 1-column grids
- **Desktop** (> 900px) — Full 2-column layouts

## 🚢 Deployment
1. Push the folder to a GitHub repository
2. Go to **Settings → Pages → Source: main branch → / (root)**
3. Your site will be live at `https://<username>.github.io/<repo-name>`
